# Bucket Sort — Algoritmos de Ordenação

 Repositório com a implementação do algoritmo de ordenação **Bucket Sort** em **C**, desenvolvido para a **Atividade Avaliativa 1** da disciplina de **Estratégias de Programação**.

---

## Sobre o Projeto

Este projeto tem como objetivo estudar, implementar e apresentar o algoritmo de ordenação **Bucket Sort**, destacando sua lógica de funcionamento, análise de complexidade e caso de uso prático.
