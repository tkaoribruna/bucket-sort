Módulo 01 · Algoritmos de distribuição

BUCKET SORT

BUCKET SORT

Um algoritmo de ordenação que troca comparações repetidas por organização espacial: espalhe os dados em grupos, ordene cada grupo por conta própria, depois junte tudo na ordem certa.

01

Introdução e conceito

Bucket sort é um algoritmo de ordenação por distribuição: em vez de comparar elementos entre si o tempo todo, ele primeiro espalha os dados de um array em vários grupos menores — os baldes (buckets) — e só depois organiza o que caiu em cada grupo, geralmente com um algoritmo mais simples como o insertion sort.

1

Espalhar (Scatter)

O conjunto de dados original é dividido em subconjuntos — os baldes. Uma função de mapeamento calcula, a partir do valor de cada elemento, em qual balde ele deve cair, com base no intervalo de valores coberto por aquele balde.

2

Juntar (Gather)

Cada balde é ordenado individualmente com um algoritmo secundário (insertion sort, quicksort, ou o próprio bucket sort aplicado de forma recursiva). No fim, os baldes são percorridos em ordem e concatenados, formando a lista final ordenada.

03

Fluxo de execução

Do ponto de vista da implementação, o algoritmo percorre sempre as mesmas quatro etapas, nesta ordem.

1

Inicialização

Criação de N baldes vazios, normalmente como listas dinâmicas, prontos para receber os elementos.

2

Distribuição

Iteração sobre o array de entrada, inserindo cada elemento no balde correto de acordo com seu valor.

3

Ordenação

Aplicação de um algoritmo de ordenação individual em cada um dos baldes preenchidos.

4

Concatenação

Junção sequencial de todos os baldes, já ordenados, para compor o array final.

04

Complexidade do algoritmo

O desempenho do bucket sort depende diretamente de como os valores de entrada se distribuem entre os baldes.

Cenário Complexidade temporal Complexidade espacial Condição de ocorrência
Melhor caso O(n + k) O(n + k) Elementos distribuídos uniformemente entre os baldes.
Caso médio O(n) O(n + k) Distribuição aleatória, sem grandes concentrações locais.
Pior caso O(n²) O(n + k) Todos os elementos concentrados em um único balde.
n — número de elementos k — número de baldes alocados

05

Pontos fortes e fracos

⚡

Desempenho

Alcança tempo linear de ordenação quando os dados de entrada seguem uma distribuição uniforme contínua — um cenário comum ao ordenar números de ponto flutuante normalizados.

🧮

Overhead de memória

Exige alocação adicional para os baldes, o que torna o consumo de espaço maior do que o de algoritmos in-place, como o quicksort ou o heapsort.

🗂️

Sensibilidade a dados

Se os dados estiverem muito agrupados (clustered), a eficiência cai rapidamente para o pior caso, já que um único balde acaba concentrando quase todos os elementos.

06

Aplicações práticas

Fora da sala de aula, a lógica de distribuição do bucket sort aparece em situações bem específicas.

01

Processamento de imagens

Quantização de cores e construção de histogramas agrupam pixels por faixas de intensidade — essencialmente um bucket sort sobre os valores de cor.

02

Ordenação externa

Quando o volume de dados não cabe em memória, dividir os registros em faixas de valor antes de processá-los em partes é uma estratégia clássica de bucketing.

03

Dados normalizados

Notas, probabilidades e coordenadas normalizadas no intervalo [0,1) tendem a se distribuir de forma uniforme — exatamente a condição em que o bucket sort atinge seu melhor desempenho.

04

Etapa do radix sort

Cada passada do radix sort — ao agrupar números por dígito — é, na prática, uma aplicação de bucket sort com dez baldes fixos.

05

Particionamento por faixas

Bancos de dados distribuídos usam range partitioning para direcionar registros a diferentes nós conforme a faixa de valor da chave — a mesma ideia de mapeamento em baldes.

06

Pré-ordenação paralela

Como os baldes são independentes entre si, cada um pode ser ordenado em paralelo — útil em implementações que exploram múltiplos núcleos ou GPUs.

07

Código-fonte

Implementação de referência em dois idiomas, usando cinco baldes distribuídos linearmente entre o menor e o maior valor do array.

bucket-sort.js 
// Ordena números distribuindo-os em baldes por intervalo de valor
function bucketSort(arr, bucketCount = 5) {
  if (arr.length <= 1) return arr;

  const min = Math.min(...arr);
  const max = Math.max(...arr);
  const range = (max - min + 1) / bucketCount;
  const buckets = Array.from({ length: bucketCount }, () => []);

  // 1. Scatter: cada valor cai no balde do seu intervalo
  for (const value of arr) {
    let idx = Math.floor((value - min) / range);
    if (idx >= bucketCount) idx = bucketCount - 1;
    buckets[idx].push(value);
  }

  // 2. Sort + 3. Gather: ordena cada balde e concatena tudo
  return buckets.flatMap(bucket => bucket.sort((a, b) => a - b));
}
# Ordena números distribuindo-os em baldes por intervalo de valor
def bucket_sort(arr, bucket_count=5):
    if len(arr) <= 1:
        return arr

    minimum, maximum = min(arr), max(arr)
    bucket_range = (maximum - minimum + 1) / bucket_count
    buckets = [[] for _ in range(bucket_count)]

    # 1. Scatter: cada valor cai no balde do seu intervalo
    for value in arr:
        index = int((value - minimum) // bucket_range)
        index = min(index, bucket_count - 1)
        buckets[index].append(value)

    # 2. Sort + 3. Gather: ordena cada balde e concatena tudo
    result = []
    for bucket in buckets:
        result.extend(sorted(bucket))
    return result
